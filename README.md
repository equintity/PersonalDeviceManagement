# PersonalDeviceManagement —— 本地个人器件库

参考 [立创开源《EDA智能器件盒》](https://oshwhub.com/course-examples/project_kjqfbdaj) 中"个人器件库 + 器件盒映射"的设计,
实现的**本地版个人器件库程序**:管理你的元器件库存,把器件映射到实体器件盒的格栅格位,
并一键自动生成可烧录的 ESP32 固件 —— 全程无需手写或修改任何代码。

```
┌──────────────────────────────┐        JSON(串口/虚拟盒)      ┌──────────────────────┐
│  本地 Web 应用(Flask)        │ ◄──────────────────────────► │  ESP32-S3 器件盒固件   │
│  · 器件库(立创批量导入/手工)  │   take / return / light /     │  · WS2812 7×9 格栅    │
│  · 器件盒映射(7×9 可调)      │   sync / qty 双向联动          │  · SSD1306 OLED       │
│  · 一键生成 PlatformIO 固件   │ ◄──── 生成的固件工程 ───────── │  · 五向键取料/退料     │
└──────────────────────────────┘                              └──────────────────────┘
```

## 功能总览

| 需求 | 实现 |
|---|---|
| ① 立创商城批量导入 + 手工维护 | 订单 `.xlsx/.xls/.csv` 多文件导入,自动识别 C编号/数量列,重复器件合并累加;C编号批量联网查询详情;全字段 CSV 往返;器件条目与自定义属性(JSON)全手工可编辑 |
| ② 与自定义器件盒联动 | 软件格栅 ↔ 硬件实时同步:连接即推送映射;硬件取料/退料事件实时扣减/回补软件库存;点击格位可点亮实体 LED;内置**虚拟器件盒**,无硬件可完整体验 |
| ③ 动态配置器件盒映射 | 默认 **7×9 = 63 格**,行/列(1×1 ~ 16×24,≤256 格)随时可调,预设 5×7 / 4×8 / 8×10;调整尺寸自动保留界内映射、移除并报告越界映射;支持一键排布 |
| ④ 自动生成 ESP32 代码 | "代码生成"页一键输出完整 PlatformIO 工程(ESP32-S3 + WS2812 + U8g2 OLED + 五向键 + NVS + JSON 协议),映射全部写进自动生成的 `box_config.h`,改映射→重新生成→烧录即可 |
| ⑤ 软件层↔代码层安全管理 | 全链路输入白名单校验(名称字符集/C编号/GPIO/尺寸上限);C 转义保证用户文本无法逃逸字符串字面量;过滤控制字符与 Unicode 双向控制符;生成结果整体扫描后才写盘;输出目录防误覆盖。详见 [docs/SECURITY.md](docs/SECURITY.md) |

## 快速开始

```bash
# 1. 安装依赖(Python ≥ 3.10)
pip install -r requirements.txt

# 2. 启动
python app.py
# → http://127.0.0.1:8321

# 3. 体验:器件库页 → 「批量导入」→ 选择 examples/lcsc_order_sample.xlsx
#    器件盒页 → 点格位分配器件 → 连接 virtual://box 虚拟盒 → 模拟取料
#    代码生成页 → 填输出目录 → 生成固件工程
```

> 导入自己真实的立创商城订单:立创商城 → 订单中心 → 导出订单明细(xlsx),直接拖入「批量导入」。

## 烧录固件到器件盒

1. 安装 [VSCode](https://code.visualstudio.com/) + PlatformIO 插件;
2. 在"代码生成"页生成固件工程,用 VSCode 打开输出目录;
3. USB 连接 ESP32-S3(立创·天际板 ESP32S3R8N8 或通用 DevKit),点 **Upload**;
4. 打开串口监视器(115200)确认固件输出 `hello` 事件;
5. 回到本软件,器件盒页选择对应 COM 口 → 「连接」,开始联动。

硬件参考配置(全部可在软件中修改):WS2812 数据脚 GPIO48、OLED SDA=40/SCL=39、五向键 46/15/41/45/42。
固件架构与串口协议详见 [docs/FIRMWARE.md](docs/FIRMWARE.md)。

运行期数据在 `data/`(SQLite)与 `uploads/`,均已 gitignore。

## 安全要点

- 仅监听 `127.0.0.1`,浏览器侧强制 CSP(禁内联脚本/外部源);
- 所有写操作入参过白名单校验,SQL 全参数化;
- 生成代码只允许出现在受控的字符串字面量与严格整数中;
- 立创接口访问带超时与限速,失败自动降级为仅编号导入;
- 串口协议双向白名单 + 长度上限,固件端同样做边界检查。

完整威胁模型与防护清单见 **[docs/SECURITY.md](docs/SECURITY.md)**。
