# 安全设计:软件层 ↔ 代码层管理机制(需求⑤)

## 威胁模型

本程序的核心风险面是:**用户可控文本会进入生成的 C 代码**。
攻击者(或误操作)若能让器件名携带代码片段(如 `"; #include "evil.h"`),
最坏情况是在用户机器上编译执行任意代码。次要风险面:本机 Web 接口、
上传文件、串口数据。

## 防线清单(按数据流顺序)

### 1. 入口校验(`pdl/security.py`)

| 项目 | 规则 |
|---|---|
| 器件名称 | 1~64 字符;字符白名单(中英文/数字/常用标点);**含控制字符或不可见字符直接拒绝**(不静默改写) |
| C 编号 | `^C\d{1,8}$`,统一大写;其余一律拒绝 |
| 数值 | 必须是 `int`(拒绝 bool/str/float 混入);范围校验(数量 0~9999999、亮度 0~255 等) |
| GPIO | ESP32-S3 实际存在的引脚白名单(0~21、26~48);按键等场景额外禁用与 Flash/PSRAM 复用的 26~37 |
| 格栅尺寸 | 行 1~16、列 1~24、总数 ≤256(防止生成超大固件数组) |
| 整数列表 | 批量操作逐项校验,上限 1000 项 |
| Unicode | 全局过滤 C0/C1 控制符、零宽字符、**双向文本控制符 U+202A-202E / U+2066-2069**(防"特洛伊源码"攻击 CVE-2021-42574)、U+2028/2029、BOM |

### 2. 代码生成(`pdl/services/codegen.py`)

- **唯一注入点**:用户数据只写进生成的 `include/box_config.h`;
  固件逻辑层来自固定模板(`firmware/template/`),生成过程只复制不拼接;
- 每个字符串经过 `c_escape()`:
  - 反斜杠、双引号转义 → 无法闭合字符串字面量;
  - 换行/制表等控制符清除或转义 → 注入内容只能停留在"一行字符串"内;
  - 转义后再扫描,结果中不允许存在任何原始控制字符;
- 每个数字经过 `c_int()`(先整数类型与范围校验,再格式化);
- 生成完成后 `scan_generated_code()` 整体扫描禁止片段
  (`system(`、`asm(`、`__attribute__`、`#include <`),命中即拒绝写盘;
- 双重验证:即使器件名绕过了入口校验直接落库(见测试
  `test_injection_neutralized`),生成层依然独立完成清洗+转义+扫描。

### 3. 输出目录保护

- 必须是绝对路径;禁止写入程序自身目录(防覆盖源代码);
- 已存在且非空的目录必须带有本工具的 `.pdl_firmware` 标记才允许写入
  (防误覆盖无关数据);标记文件内含生成时间与配置哈希,可追溯。

### 4. Web 接口

- Flask 仅绑定 `127.0.0.1`(可用 `--host` 显式放开,默认最小暴露);
- 全部接口要求 JSON 对象,统一错误信封,不回显堆栈;
- 安全响应头:`Content-Security-Policy`(禁内联脚本、禁外源)、
  `X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`、
  `Referrer-Policy: no-referrer`、`Cache-Control: no-store`;
- 上传:扩展名白名单(`.xlsx/.xls/.csv`)、单文件 ≤20MB、总请求 ≤25MB、
  随机文件名落盘(防路径注入),显示名另行清洗;
- SQL 全部参数化(LIKE 查询对 `%/_/\` 转义),无任何字符串拼接。

### 5. 串口协议(软件端 + 固件端)

- 命令/事件双白名单;单条消息 ≤512 字节,超长即弃;
- 收到的事件字段裁剪后才进入事件流,不会把硬件数据当指令执行;
- 固件端独立复核:cell 越界丢弃、qty 上限 65535、sync 条目数 ≤ 格栅总数、
  JSON 解析失败仅回 `log` 事件。

### 6. 外部接口

- 立创商品接口仅 GET 查询,固定域名、10s 超时、0.4s 限速、失败静默降级;
- 单批 ≤300 个编号,防滥用。

## 已知边界(诚实声明)

- 本地多用户隔离不在目标内:同一台机器的本地用户都能访问 8321 端口;
- `.xls` 旧格式依赖可选的 `xlrd`,如无则给出明确提示;
- 立创接口为非官方公开端点,字段可能变化 —— 解析失败不影响文件导入;
- `c_escape` 的安全边界是"字符串字面量",`box_config.h` 中的数组大小、
  引脚号等仍由白名单整数保证,两者缺一不可。
