# 使用手册

## 启动

```bash
pip install -r requirements.txt
python app.py            # 默认 http://127.0.0.1:8321
python app.py --port 9000
```

## 1. 导入立创商城数据(需求①)

**途径 A:订单文件批量导入**
1. 立创商城网站 → 「我的订单」→ 导出订单明细(xlsx);
2. 器件库页 → 「⬇ 批量导入」→ 选择一个或多个订单文件;
3. 勾选"自动联网补充详情"后,软件按 C 编号调用立创公开接口补充
   名称/封装/品牌/描述/单价(失败自动降级为仅编号入库,不影响导入);
4. 重复导入同一订单:已存在的器件**数量自动累加**,不会重复建条目。

**途径 B:C 编号批量导入**:文本框每行一个 C 编号(如 `C25704`),粘贴导入。

**手工创建**:「＋ 新建器件」—— C编号可选;自定义属性用 JSON 表达,
例如 `{"耐压":"50V","精度":"±10%"}`。

**搜索与维护**:顶部搜索框按名称/C编号/描述/封装/品牌即时过滤;
点击库存数字可改数量;支持勾选批量删除;「导出 CSV」可全量备份
(全字段 CSV 再导入时按合并模式恢复)。

## 1.5 器件价格更新

「⟳ 刷新价格」按钮批量拉取最新价格:

- **匹配规则**:有 C 编号 → 立创接口**精确查询**(同时获取下架状态);
  无 C 编号 → 按**型号 MPN** 在 JLCPCB 器件库**严格相等**匹配,
  命中后自动回填 C 编号便于下次精确刷新;
- **状态标记**(显示在价格列):
  `已更新`(绿)= 拿到最新价;`无匹配`(黄)= 型号/C编号无精确结果;
  `已下架`(红)= 接口生命周期状态非正常(如 sold_out);`失败`(红)= 网络异常;
- **结果摘要**:弹窗分类列出 已更新(旧值→新值)/无匹配/已下架/失败/跳过
  (无编号且无型号的器件),以及耗时与"还有更多"提示(单批上限 100);
- 型号在「新建/编辑器件」中填写;来源接口返回的为 **USD** 价,
  价格列以 `$` 前缀区分,手填价格不带前缀;
- 数据来源与限制详见 `docs/DESIGN.md` 的"价格数据源调研"一节。

## 2. 器件盒映射(需求②③)

- 进入「器件盒映射」页:左侧配置面板,右侧 7×9 格栅;
- **调整尺寸**:输入行列数或点预设(5×7/4×8/8×10)→ 应用;
  界内映射自动保留,越界映射被移除并提示;
- **分配器件**:点任意格位 → 「分配器件」→ 搜索选择;
  「解除映射」释放格位;「一键排布」按器件库最新顺序自动填满;
- **硬件配置**:LED 引脚/亮度/排列(逐行或蛇形)/设备名/五向键/OLED 引脚,
  全部带 GPIO 白名单校验,保存后用于生成固件;
- **联动**:
  - 「连接」:选择 COM 口或 `virtual://box`(虚拟盒);
    连接成功立即推送全部映射与库存;
  - 点格位「点亮测试」→ 实体 LED(或虚拟盒)对应格位亮黄灯;
  - 硬件按键取料/退料 → 本软件库存实时 -1/+1,底部状态栏与弹窗提示;
  - 「同步映射到硬件」随时手动全量推送。

> 无硬件时选 `virtual://box`,用"虚拟盒模拟操作"三个按钮即可体验完整联动闭环。

## 3. 生成 ESP32 固件(需求④)

1. 「代码生成」页确认 `box_config.h` 实时预览(即将写入固件的内容);
2. 填写输出目录(如 `D:\Pre\Masterpiece\MyBoxFirmware`)→ 「生成固件工程」;
3. 用 VSCode + PlatformIO 打开输出目录 → Upload 烧录;
4. 串口监视器(115200)看到 `hello` 即成功;回到软件连接该 COM 口。

修改映射后**重新生成即可**,永远不需要手改代码;输出目录非空时
仅接受本工具生成的固件目录(防误覆盖)。

## 4. 修改记录与排错

| 现象 | 处理 |
|---|---|
| 导入后没有详情 | 未勾选联网补充或网络受限;可稍后重新导入同一文件合并补充 |
| 提示"C编号格式错误" | 检查是否为 C+数字(≤8 位);无效行会被跳过并计入 skipped |
| 无法连接串口 | 确认未占用(PlatformIO 监视器需关闭);pyserial 已安装 |
| 生成被拒绝"目标目录非空" | 换新目录,或选择原先生成的固件目录(有 .pdl_firmware 标记) |
| OLED 中文显示不全 | chinese2 字体覆盖常用简体字,生僻字可改用拼音/英文名 |
| 串口事件无反应 | 点「同步映射到硬件」;查看底部事件日志条 |
